# **App Name**: GetHeard

## Core Features:

- Hero Section: Implement a Hero section with the tagline 'Sometimes all we need is someone to listen.'
- Founder Profiles: Design and display profiles of the founders (two software engineers from Mumbai) with photos and short bios.
- Testimonials Section: Showcase testimonials with photos and two-line reviews from users.
- Booking Form: Implement a 'Book a Free Call' section with a form to collect user details and questions.
- AI-Powered Summary: AI-powered tool to analyze the content of the booking form and prepare a summary for the support provider to understand the caller's emotional state and needs beforehand.

## Style Guidelines:

- Primary color: Calming blue (#A0E9FF) to promote trust and serenity.
- Secondary color: Soft green (#BFFCC6) to represent growth and healing.
- Accent color: Warm orange (#FFB347) for call-to-action buttons, like booking calls.
- Clean and readable typography for body text.
- Use simple, empathetic icons to represent different aspects of emotional support.
- Clean, well-spaced layout to reduce visual clutter and enhance readability.
- Subtle animations to create a welcoming and engaging user experience.
